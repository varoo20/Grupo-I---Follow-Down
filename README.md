# Grupo-I---Juegos-en-Red
Grupo I de Juegos en Red: Jorge, Carla y yo

INTEGRANTES: Jorge Franco Lopez de Gauna, Álvaro Montero Carrasco y Carla Urdiales Aguado 

El videojuego que se va a desarrollar estará compuesto por una serie de puzles que los jugadores deberán resolver de manera cooperativa, fomentando la comunicación y la colaboración entre ellos. El juego contará con una estética sencilla y un diseño visual en 2D. 

Como referencia para su desarrollo, se tomarán como inspiración varios videojuegos de características similares, entre los que destacan Fireboy and Watergirl y Pico Park. Ambos juegos se caracterizan por plantear diferentes desafíos que requieren la cooperación entre los jugadores para poder avanzar y superar los distintos niveles.
